# Генерация преобразований DTO

Из директории `backend` выполните `go run ./tools/dtomap` либо `make generate`.
Генератор читает независимые объявления `internal/model/entities.go` и
`pkg/api/v1/api.gen.go`, затем записывает только
`internal/api/v1/mapping.gen.go`. Доменная модель не создаётся и не изменяется.

Для общих типов генерируются явные преобразования с литералами структур,
приведениями перечислений и e-mail, `ptr.Map` и `slice.Map`. Функции не
используют JSON, reflection или преобразование DTO во время выполнения.

Различия состава полей, включая новые необязательные поля, формы типов и
значений перечислений прерывают генерацию до записи результата. При изменении
контракта нужно отдельно согласовать доменную модель и сервисную логику.
`make generate-check` повторяет обе генерации и сравнивает оба сохранённых
артефакта. Порядок типов и импортов фиксирован; результат проходит `gofmt`.

Для проверки небольших примеров доступны аргументы `-model`, `-api` и `-out`.
Тесты запускаются командой `go test ./tools/dtomap`.
