# Тестовые данные TourneyHub

Запусти стенд по [инструкции](README.md). Скрипт восстановит из Git **31 синтетический аккаунт, 19 команд, 46 турниров, 11 дисциплин, 35 заявок и 30 матчей**. Сохранены ID, связи между аккаунтами, составы, роли, сетки, таблицы, результаты, история рейтинга, уведомления и записи аудита. Даты сдвигаются относительно первого запуска, чтобы сохранялись открытая регистрация, будущая регистрация и сценарии с уже начавшимися матчами. У ожидающего подтверждения результата остаётся время для проверки.

## Где взять пароли и ссылки

Открой `tests/.qa/tourneyhub-qa/accounts.md` после запуска. Там указаны логины и пароли всех пользователей. В соседнем `test-cases.md` данные конкретных ролей уже вставлены рядом с шагами. Пароли генерируются заново для отдельного QA-проекта. Токен ngrok, старые пароли, сессии, письма и одноразовые ссылки прежнего стенда в снимок не входят. Новые письма и ссылки можно получить через приложение и Mailpit.

- Команды «Север», «Восток», «Вектор», «Ритм», «Факел», «Орион», «Каскад» и «Горизонт». У каждой есть капитан и игроки.

Источник набора — [`fixtures/snapshot.sql`](fixtures/snapshot.sql). Связанные аккаунты, идентификаторы сценариев и ожидаемые количества записаны в [`fixtures/manifest.json`](fixtures/manifest.json).
