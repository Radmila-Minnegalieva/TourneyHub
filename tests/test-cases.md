# Тест-кейсы TourneyHub

## TC-01. Отображение каталога турниров

**Предусловие:** клиентское приложение запущено.

**Шаги:**
1. Открыть главную страницу приложения.
2. Перейти к каталогу турниров.

**Ожидаемый результат:** отображается список доступных турниров без ошибок интерфейса.

---

## TC-02. Отображение данных турнира

**Предусловие:** в каталоге существует хотя бы один турнир.

**Шаги:**
1. Открыть каталог турниров.
2. Проверить карточку турнира.

**Ожидаемый результат:** для турнира отображаются основные данные: название, дисциплина, статус и дата начала.

---

## TC-03. Получение списка турниров через API

**Предусловие:** серверная часть приложения запущена.

**Шаги:**
1. Отправить GET-запрос на `/api/tournaments`.
2. Проверить полученный ответ.

**Ожидаемый результат:** сервер возвращает успешный ответ и список турниров в формате JSON.

---

## TC-04. Получение турнира по идентификатору

**Предусловие:** в системе существует турнир с известным идентификатором.

**Шаги:**
1. Отправить GET-запрос на `/api/tournaments/{id}`.
2. Проверить полученный объект.

**Ожидаемый результат:** сервер возвращает данные турнира с указанным идентификатором.

---

## TC-05. Запрос несуществующего турнира

**Предусловие:** серверная часть приложения запущена.

**Шаги:**
1. Отправить GET-запрос на `/api/tournaments/{id}`, указав несуществующий идентификатор.
2. Проверить ответ сервера.

**Ожидаемый результат:** сервер корректно сообщает, что турнир не найден.

---

## TC-06. Проверка пустого списка турниров

**Предусловие:** в источнике данных отсутствуют турниры.

**Шаги:**
1. Открыть каталог турниров.
2. Проверить состояние страницы.

**Ожидаемый результат:** приложение корректно обрабатывает отсутствие данных и не завершается с ошибкой.
