# Ручные тест-кейсы TourneyHub по ТЗ ЛР1

Сайт — [TourneyHub]({{site}}), [вход]({{login}}), [Mailpit]({{mailpit}}), [Swagger]({{swagger}}). Этот документ для выполнения открывай из `tests/.qa/<имя-проекта>/test-cases.md`. Скрипт запуска подставит адреса и пароли. В двухроленных сценариях используй обычное и приватное окно или разные профили браузера.

Для каждого кейса запиши статус **пройден / не пройден / заблокирован**, фактический результат и ссылку или скриншот. Подтверждение, решение спора и одобрение заявки меняют данные. Если готовый сценарий уже использован, запусти отдельный QA-проект по инструкции. Для первого прогона начни с TC-01, TC-06, TC-11, TC-12 и TC-15.

**Ожидается** — до подтверждения вход закрыт. После сброса работает только новый пароль. Использованная и просроченная ссылки отклоняются. Новое письмо для публичного запуска содержит адрес текущего ngrok.

## Отдельные прогоны по ТЗ

Ручной прогон проверяет функциональные требования. Для п. 4.1.3 отдельно нужны нагрузочные испытания на выделенном стенде, включая p95 не более 300 мс при 200 запросах в секунду. Для остальных нефункциональных пунктов отдельно проверяются резервное копирование и восстановление, доступность, браузеры и WCAG. Записывай результаты отдельно от ручных кейсов.
