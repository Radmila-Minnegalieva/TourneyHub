# TourneyHub

TourneyHub — учебная веб-платформа для организации и проведения турниров.

## Назначение проекта

Система предназначена для автоматизации основных этапов проведения турниров: регистрации участников и команд, формирования турниров, расписания, турнирных сеток, фиксации результатов и отображения рейтингов.

- React
- Vite

### Серверная часть
- Go

### Система контроля версий
- Git

## Структура репозитория

- `frontend/` — клиентская часть приложения;
- `backend/` — серверная часть приложения;
- `tests/` — материалы тестирования;
- `docs/` — проектная и автоматически сформированная документация.

## Основные возможности TourneyHub

- просмотр каталога турниров;
- создание и проведение турниров;
- работа с командами и участниками;
- формирование турнирных сеток и расписания;
- фиксация результатов матчей;
- ведение рейтингов.
